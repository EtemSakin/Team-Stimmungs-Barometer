# Spec
1. Wähle ein Epic aus specs/roadmap.md, standardmäßig das erste unspezifizierte.
2. Erörtere UI/UX, Technologien, Datenmodell, Edge Cases.
3. Stelle Fragen in specs/{nr}-{name}-brainstorming.md in Runden, mit Optionen [ ] und vorausgewählter Empfehlung.
4. Ergänze neue Fragen nur append-only, nie alte Antworten verändern.
5. Nach vollständiger Klärung erstelle specs/{nr}-{name}-specification.md.
6. Keine Implementierung im Spec-Modus.
